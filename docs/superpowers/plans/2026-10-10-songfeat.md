# songfeat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn any symbolic music file into one typed, documented feature record per part, with emphasis on vocal skill and difficulty.

**Architecture:** Four stages — load, prepare, detect vocal line, extract — over a part-centric model. Shared derivations (intervals, phrases, runs, prevailing key) are computed once per part on a cached `PartContext`, so features cannot silently disagree about definitions. Extraction produces typed `FeatureRecord` objects and hands them to a sink; serialisation never happens in extraction code. music21 supplies ~136 borrowed features through an adapter and remains replaceable.

**Tech Stack:** Python 3.12+, music21 10.1.0, Pydantic v2, pytest. Google Sheets client optional.

**Spec:** `docs/superpowers/specs/2026-10-10-songfeat-design.md`

## Global Constraints

- Python 3.12 or newer. The project venv is CPython 3.12.3.
- Pydantic v2 is a new dependency; add it to `requirements.txt` (UTF-8, LF, alphabetical — the file was re-encoded in commit `9d75982`).
- The Google client is an **optional** dependency. `import songfeat` must never require it; only constructing `SheetsSink` does.
- One record per part. Never pool notes across parts.
- Feature columns are registry-driven and emitted in stable registry order.
- Borrowed features are namespaced: `js_` for jSymbolic, `nat_` for music21 native. Our own features carry no prefix.
- Every feature declares: `name`, `group`, `scope` (`"part"` or `"piece"`), `source`, `dtype`, `description`, and `citation` (may be `None`).
- Errors live in `FeatureRecord.errors`, keyed by feature name. `flat()` projects them to `_error_<name>` columns for tabular sinks only.
- Passaggio bands are the nine ranges at `src/tessitura.py:76-84`, lifted to named constants. Do not retype them as literals in feature code.
- Tessitura quartiles are emitted **both** duration-weighted and count-weighted. Do not pick one.
- No composite difficulty score anywhere in this plan.
- Existing behaviour that must survive: `drop_trailing_marker` only strips a final C1 when nothing else in the part sits that low.

## Review Focus

These input classes are implied by the spec but are not naturally exercised by a happy-path feature test. Each line names the task that owns its test.

1. **A part with zero notes** (an empty staff, a rest-only part). Every feature must return `None` rather than raise `StatisticsError` or divide by zero. — Task 2.
2. **A part with exactly one note.** Intervals, leaps and phrase gaps have no pairs; variance and entropy are undefined. Features must return `None`, not `0.0`, which would be a real measured value. — Task 3.
3. **A file with no tempo mark.** Seconds fall back to 120 BPM, so every duration-weighted feature still computes rather than returning `None` or `inf`. — Task 9.
4. **A polyphonic part** (a piano staff of chords) fed to melodic features. "Melodic interval" is ill-defined across simultaneous notes; the context must derive intervals from a monophonic reduction and record that it did. — Task 3.
5. **A file where no part is vocal** (a string quartet). All parts get low confidence, `is_vocal_candidate` is `False` everywhere, nothing crashes, and vocal features still emit numbers that are simply not about singing. — Task 6.

```python
def _collect_notes(
    parts: list[stream.Part], tempo_map: list[tuple[float, float]]
) -> list[list[Note]]:
    per_part: list[list[Note]] = []
    for index, part in enumerate(parts):
        collected: list[Note] = []
        for element in part.flatten().recurse().notes:
            onset = float(element.offset)
            duration = float(element.duration.quarterLength)
            onset_seconds = quarters_to_seconds(onset, tempo_map)
            duration_seconds = (
                quarters_to_seconds(onset + duration, tempo_map) - onset_seconds
            )
            lyric = getattr(element, "lyric", None) or None
            pitches = (
                element.pitches
                if isinstance(element, m21_chord.Chord)
                else [element.pitch]
            )
            for pitch in pitches:
                collected.append(
                    Note(
                        midi=int(pitch.midi),
                        onset=onset,
                        duration=duration,
                        part=index,
                        onset_seconds=onset_seconds,
                        duration_seconds=duration_seconds,
                        lyric=lyric,
                        is_chord_member=len(pitches) > 1,
                    )
                )
        collected.sort(key=lambda n: (n.onset, n.midi))
        per_part.append(collected)
    return per_part
```

```python
PartExtractor = Callable[[Part, Piece], dict[str, Any]]


@dataclass(frozen=True)
class FeatureSpec:
    name: str
    group: str
    scope: str            # "part" or "piece"
    source: str           # "songfeat" | "jsymbolic" | "music21-native"
    description: str
    fields: tuple[str, ...]
    func: Callable
    dtype: str = "float"
    citation: str | None = None
    #: Formats where this feature is fully meaningful. MIDI carries no pitch
    #: spelling, so chromaticism features are inferred there and stronger from
    #: MusicXML. None means "equally valid for every supported format".
    best_with: tuple[str, ...] | None = None


def feature(name, group, scope, source, description, fields,
            dtype="float", citation=None, best_with=None):
    if scope not in ("part", "piece"):
        raise ValueError(f"scope must be 'part' or 'piece', got {scope!r}")

    def decorator(func):
        if name in _REGISTRY:
            raise ValueError(f"duplicate feature name: {name}")
        _REGISTRY[name] = FeatureSpec(
            name=name, group=group, scope=scope, source=source,
            description=description, fields=tuple(fields), func=func,
            dtype=dtype, citation=citation, best_with=best_with,
        )
        return func

    return decorator


def _run(specs, *args) -> dict[str, Any]:
    out: dict[str, Any] = {}
    errors: dict[str, str] = {}
    for spec in specs:
        try:
            out.update(spec.func(*args))
        except Exception as exc:  # noqa: BLE001 — deliberate per-feature isolation
            out.update(dict.fromkeys(spec.fields))
            errors[spec.name] = f"{type(exc).__name__}: {exc}"
    out["_errors"] = errors
    return out


def extract_part(part, piece, groups_filter=None) -> dict[str, Any]:
    wanted = set(groups_filter) if groups_filter else None
    specs = [
        s for s in _REGISTRY.values()
        if s.scope == "part" and (wanted is None or s.group in wanted)
    ]
    return _run(specs, part, piece)


def extract_piece(piece, groups_filter=None) -> dict[str, Any]:
    wanted = set(groups_filter) if groups_filter else None
    specs = [
        s for s in _REGISTRY.values()
        if s.scope == "piece" and (wanted is None or s.group in wanted)
    ]
    return _run(specs, piece)
```

```python
# songfeat/context.py
"""Derivations shared across features, computed once per part.

Features read phrases, intervals and runs from here rather than deriving
them locally, so that every feature that mentions a "phrase" means the
same thing.
"""

from __future__ import annotations

from functools import cached_property
from itertools import groupby

from .constants import PHRASE_GAP_QUARTERS, SUSTAINED_MIN_SECONDS
from .model import KeyMark, Note, Part, Piece


class PartContext:
    def __init__(self, part: Part, piece: Piece) -> None:
        self.part = part
        self.piece = piece

    @cached_property
    def is_polyphonic(self) -> bool:
        onsets = [n.onset for n in self.part.notes]
        return len(onsets) != len(set(onsets))

    @cached_property
    def monophonic(self) -> list[Note]:
        """One note per onset — the highest, which carries the melody."""
        notes = sorted(self.part.notes, key=lambda n: (n.onset, n.midi))
        return [
            max(group, key=lambda n: n.midi)
            for _, group in groupby(notes, key=lambda n: n.onset)
        ]

    @cached_property
    def intervals(self) -> list[int]:
        line = self.monophonic
        return [b.midi - a.midi for a, b in zip(line, line[1:])]

    @cached_property
    def phrases(self) -> list[list[Note]]:
        """Runs of notes separated by rests longer than the gap threshold."""
        line = self.monophonic
        if not line:
            return []
        phrases: list[list[Note]] = [[line[0]]]
        for previous, current in zip(line, line[1:]):
            gap = current.onset - (previous.onset + previous.duration)
            if gap >= PHRASE_GAP_QUARTERS:
                phrases.append([current])
            else:
                phrases[-1].append(current)
        return phrases

    @cached_property
    def sustained(self) -> list[Note]:
        return [
            n for n in self.part.notes
            if (n.duration_seconds or 0.0) >= SUSTAINED_MIN_SECONDS
        ]

    def prevailing_key(self, onset: float) -> KeyMark | None:
        marks = [k for k in self.piece.keys if k.onset <= onset]
        return max(marks, key=lambda k: k.onset) if marks else None
```

```python
# songfeat/record.py
"""The typed boundary object. Extraction produces these; sinks consume them."""

from __future__ import annotations

from typing import Any

from pydantic import BaseModel, Field

FeatureValue = float | int | str | bool | None


class FeatureRecord(BaseModel):
    """One analysed part."""

    source_path: str
    source_format: str
    part_index: int
    part_name: str | None = None
    is_vocal_candidate: bool = False
    vocal_confidence: float = Field(default=0.0, ge=0.0, le=1.0)
    features: dict[str, FeatureValue] = Field(default_factory=dict)
    errors: dict[str, str] = Field(default_factory=dict)

    #: Identity columns, in the order tabular sinks emit them.
    IDENTITY: tuple[str, ...] = (
        "source_path", "source_format", "part_index", "part_name",
        "is_vocal_candidate", "vocal_confidence",
    )

    def flat(self) -> dict[str, Any]:
        """Identity fields merged with features, for tabular sinks."""
        row: dict[str, Any] = {name: getattr(self, name) for name in self.IDENTITY}
        row.update(self.features)
        for name, message in self.errors.items():
            row[f"_error_{name}"] = message
        return row
```

Note: `IDENTITY` must be declared as a `ClassVar` so Pydantic does not treat it as a field:

```python
    IDENTITY: ClassVar[tuple[str, ...]] = (...)
```

```python
# songfeat/sinks/base.py
"""Sinks receive records. Extraction never serialises."""

from __future__ import annotations

from typing import Protocol, runtime_checkable

from ..record import FeatureRecord


@runtime_checkable
class Sink(Protocol):
    def open(self, schema: list[str]) -> None: ...
    def write(self, record: FeatureRecord) -> None: ...
    def close(self) -> None: ...


class BaseSink:
    """Context-manager plumbing shared by the concrete sinks."""

    def open(self, schema: list[str]) -> None:
        self.schema = list(schema)

    def write(self, record: FeatureRecord) -> None:
        raise NotImplementedError

    def close(self) -> None:
        pass

    def __enter__(self):
        return self

    def __exit__(self, *exc_info) -> None:
        self.close()


class MemorySink(BaseSink):
    """Collects records in a list. For tests and small in-process runs."""

    def __init__(self) -> None:
        self.records: list[FeatureRecord] = []

    def write(self, record: FeatureRecord) -> None:
        self.records.append(record)
```

```python
# songfeat/sinks/files.py
from __future__ import annotations

import csv
import json

from ..record import FeatureRecord
from .base import BaseSink


class CsvSink(BaseSink):
    """Wide rows via flat(). Buffers, because error columns are only known
    once every record has been seen."""

    def __init__(self, path: str) -> None:
        self.path = path
        self._rows: list[dict] = []

    def write(self, record: FeatureRecord) -> None:
        self._rows.append(record.flat())

    def close(self) -> None:
        extra = sorted({k for row in self._rows for k in row if k not in self.schema})
        with open(self.path, "w", newline="", encoding="utf-8") as handle:
            writer = csv.DictWriter(
                handle, fieldnames=self.schema + extra, extrasaction="ignore"
            )
            writer.writeheader()
            writer.writerows(self._rows)


class JsonlSink(BaseSink):
    """One record per line. Streams; the default for large batches."""

    def __init__(self, path: str) -> None:
        self.path = path
        self._handle = None

    def open(self, schema: list[str]) -> None:
        super().open(schema)
        self._handle = open(self.path, "w", encoding="utf-8")

    def write(self, record: FeatureRecord) -> None:
        self._handle.write(record.model_dump_json() + "\n")

    def close(self) -> None:
        if self._handle:
            self._handle.close()
            self._handle = None


class JsonSink(BaseSink):
    """A single array. Convenient for small runs; holds everything in memory."""

    def __init__(self, path: str) -> None:
        self.path = path
        self._records: list[FeatureRecord] = []

    def write(self, record: FeatureRecord) -> None:
        self._records.append(record)

    def close(self) -> None:
        with open(self.path, "w", encoding="utf-8") as handle:
            json.dump([r.model_dump() for r in self._records], handle, indent=2)
```

```python
# songfeat/vocal.py
"""Identify which part carries the sung line.

Returns the evidence alongside the score so that a wrong guess can be
inspected rather than silently believed.
"""

from __future__ import annotations

from dataclasses import dataclass, field

from .context import PartContext
from .model import Part, Piece

#: Generous outer bounds of the human singing range, in MIDI numbers (E2-C6).
VOCAL_LOW, VOCAL_HIGH = 40, 84

#: Instrument or part names that indicate singing.
VOCAL_WORDS = ("voice", "vocal", "soprano", "alto", "tenor", "bass",
               "baritone", "mezzo", "sing", "chant")

#: How much each signal contributes. They sum to 1.0.
WEIGHTS = {"lyrics": 0.45, "monophony": 0.25, "range": 0.20, "naming": 0.10}


@dataclass
class VocalEvidence:
    confidence: float
    is_candidate: bool
    signals: dict[str, float] = field(default_factory=dict)


def _range_score(part: Part) -> float:
    """Fraction of notes inside the plausible singing range."""
    inside = sum(1 for n in part.notes if VOCAL_LOW <= n.midi <= VOCAL_HIGH)
    return inside / len(part.notes)


def _naming_score(part: Part) -> float:
    haystack = f"{part.name or ''} {part.instrument or ''}".lower()
    return 1.0 if any(word in haystack for word in VOCAL_WORDS) else 0.0


def detect_vocal(part: Part, piece: Piece) -> VocalEvidence:
    if part.is_empty:
        return VocalEvidence(confidence=0.0, is_candidate=False, signals={})

    context = PartContext(part, piece)
    signals = {
        "lyrics": 1.0 if any(n.lyric for n in part.notes) else 0.0,
        "monophony": len(context.monophonic) / len(part.notes),
        "range": _range_score(part),
        "naming": _naming_score(part),
    }
    confidence = sum(WEIGHTS[k] * v for k, v in signals.items())
    return VocalEvidence(
        confidence=round(confidence, 4),
        is_candidate=confidence >= 0.5,
        signals=signals,
    )
```

```python
# songfeat/pipeline.py
"""load -> prepare -> detect -> extract -> record."""

from __future__ import annotations

import os
from typing import Iterable, Iterator

from .features import base as features_base
from .loaders import ParseError, UnsupportedFormatError, load
from .record import FeatureRecord
from .sinks.base import Sink
from .vocal import detect_vocal


def analyze_file(
    path: str,
    groups_filter: Iterable[str] | None = None,
    drop_trailing_marker: bool = False,
) -> Iterator[FeatureRecord]:
    piece = load(path, drop_trailing_marker=drop_trailing_marker)
    piece_features = features_base.extract_piece(piece, groups_filter)
    piece_errors = piece_features.pop("_errors", {})

    for part in piece.parts:
        part_features = features_base.extract_part(part, piece, groups_filter)
        errors = {**piece_errors, **part_features.pop("_errors", {})}
        evidence = detect_vocal(part, piece)
        yield FeatureRecord(
            source_path=piece.source_path,
            source_format=piece.source_format,
            part_index=part.index,
            part_name=part.name,
            is_vocal_candidate=evidence.is_candidate,
            vocal_confidence=evidence.confidence,
            features={**piece_features, **part_features},
            errors=errors,
        )


def run(
    paths: Iterable[str],
    sink: Sink,
    groups_filter: Iterable[str] | None = None,
    drop_trailing_marker: bool = False,
    on_progress=None,
) -> tuple[int, list[tuple[str, str]]]:
    """Analyse every path into the sink. One bad file never stops the batch."""
    sink.open(features_base.schema(groups_filter))
    count = 0
    failures: list[tuple[str, str]] = []
    try:
        for path in paths:
            try:
                for record in analyze_file(path, groups_filter, drop_trailing_marker):
                    sink.write(record)
                    count += 1
            except (ParseError, UnsupportedFormatError, FileNotFoundError) as exc:
                failures.append((path, f"{type(exc).__name__}: {exc}"))
            except Exception as exc:  # noqa: BLE001
                failures.append((path, f"{type(exc).__name__}: {exc}"))
            if on_progress:
                on_progress(path)
    finally:
        sink.close()
    return count, failures
```

```python
# songfeat/features/music21_adapter.py
"""Expose music21's jSymbolic and native extractors as songfeat features.

music21 remains a replaceable source of features: it supplies values, it
does not own the contract. Each part is rebuilt as a single-part score so
that extractors measure one line at a time.
"""

from __future__ import annotations

import re
from typing import Any

from music21 import note as m21_note
from music21 import features as m21_features
from music21 import stream
from music21.features import jSymbolic, native

from ..model import Part, Piece
from .base import feature

#: Extractors that describe instrumentation or multi-part texture. Measured
#: against a single reconstructed part they would return a confident wrong
#: number, so they are not registered at all.
SKIPPED_EXTRACTORS = {
    "AcousticGuitarFractionFeature", "BrassFractionFeature",
    "ElectricGuitarFractionFeature", "ElectricInstrumentFractionFeature",
    "InstrumentsPresentFeature", "NumberOfPitchedInstrumentsFeature",
    "NumberOfUnpitchedInstrumentsFeature", "OrchestralStringsFractionFeature",
    "PercussionPrevalenceFeature", "SaxophoneFractionFeature",
    "StringEnsembleFractionFeature", "StringKeyboardFractionFeature",
    "ViolinFractionFeature", "WoodwindsFractionFeature",
    "UnpitchedInstrumentsPresentFeature", "NotePrevalenceOfPitchedInstrumentsFeature",
    "NotePrevalenceOfUnpitchedInstrumentsFeature",
    "TimePrevalenceOfPitchedInstrumentsFeature",
    "VariabilityOfNotePrevalenceOfPitchedInstrumentsFeature",
    "VariabilityOfNotePrevalenceOfUnpitchedInstrumentsFeature",
    "MaximumNumberOfIndependentVoicesFeature",
    "AverageNumberOfIndependentVoicesFeature",
    "VariabilityOfNumberOfIndependentVoicesFeature",
}

CITATIONS = {
    "jsymbolic": (
        "McKay, C. and Fujinaga, I. (2006). jSymbolic: A feature extractor "
        "for MIDI files. ICMC."
    ),
    "music21-native": (
        "Cuthbert, M. S. and Ariza, C. (2010). music21: A toolkit for "
        "computer-aided musicology. ISMIR."
    ),
}


def to_snake(class_name: str) -> str:
    """AverageMelodicIntervalFeature -> average_melodic_interval"""
    stem = class_name[: -len("Feature")] if class_name.endswith("Feature") else class_name
    return re.sub(r"(?<!^)(?=[A-Z])", "_", stem).lower()


def _as_score(part: Part) -> stream.Score:
    """Rebuild one normalised part as a music21 score."""
    line = stream.Part()
    for note in sorted(part.notes, key=lambda n: n.onset):
        element = m21_note.Note(note.midi)
        element.quarterLength = note.duration or 0.25
        line.insert(note.onset, element)
    return stream.Score([line])


def _make_extractor(cls, column: str):
    def extract(part: Part, piece: Piece) -> dict[str, Any]:
        if part.is_empty:
            return {column: None}
        result = cls(_as_score(part)).extract()
        value = result.vector[0] if len(result.vector) == 1 else sum(result.vector)
        return {column: round(float(value), 6)}

    return extract


def register_music21_features() -> int:
    registered = 0
    for module, group, source in (
        (jSymbolic, "jsymbolic", "jsymbolic"),
        (native, "native", "music21-native"),
    ):
        for attribute in vars(module).values():
            if not isinstance(attribute, type):
                continue
            if not issubclass(attribute, m21_features.FeatureExtractor):
                continue
            if attribute is m21_features.FeatureExtractor:
                continue
            if attribute.__name__ in SKIPPED_EXTRACTORS:
                continue
            prefix = "js_" if group == "jsymbolic" else "nat_"
            column = prefix + to_snake(attribute.__name__)
            feature(
                name=column, group=group, scope="part", source=source,
                description=(getattr(attribute, "description", None)
                             or attribute.__name__),
                fields=(column,), citation=CITATIONS[source],
            )(_make_extractor(attribute, column))
            registered += 1
    return registered
```

```python
# songfeat/features/vocal_pitch.py
"""Tessitura, range and vocal load.

Quartiles are emitted under both duration weighting and count weighting.
The reference spreadsheet and the reference CLI disagree about which one
the published tessitura uses; see docs/superpowers/specs for the numbers.
"""

from __future__ import annotations

from typing import Any

from ..constants import SUSTAINED_MIN_SECONDS
from ..context import PartContext
from ..model import Part, Piece
from .base import feature

TESSITURA_FIELDS = (
    "q0_hz", "q1_hz_dur", "q2_hz_dur", "q3_hz_dur", "q4_hz",
    "q1_hz_cnt", "q2_hz_cnt", "q3_hz_cnt",
    "tessitura_width_dur", "tessitura_width_cnt",
)

LOAD_FIELDS = (
    "cycle_dose", "time_dose_seconds", "rest_seconds", "rest_ratio",
    "sustained_note_count", "sustained_seconds",
)


def midi_to_hz(midi: float) -> float:
    return 440.0 * (2.0 ** ((midi - 69) / 12.0))


def weighted_quantile(values, weights, q: float) -> float:
    """Smallest value whose cumulative weight reaches ``q`` of the total."""
    pairs = sorted(zip(values, weights))
    total = sum(w for _, w in pairs)
    if total <= 0:
        return float(pairs[len(pairs) // 2][0])
    target = q * total
    running = 0.0
    for value, weight in pairs:
        running += weight
        if running >= target:
            return float(value)
    return float(pairs[-1][0])


@feature(
    name="tessitura", group="vocal", scope="part", source="songfeat",
    description=(
        "Pitch quartiles in Hz. Emitted twice: weighted by sounding duration "
        "and by note count, because the reference data and the reference "
        "implementation disagree about which defines tessitura."
    ),
    fields=TESSITURA_FIELDS,
)
def tessitura(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(TESSITURA_FIELDS)

    freqs = [midi_to_hz(n.midi) for n in part.notes]
    durations = [n.duration_seconds or 0.0 for n in part.notes]
    counts = [1.0] * len(freqs)

    q1d = weighted_quantile(freqs, durations, 0.25)
    q2d = weighted_quantile(freqs, durations, 0.50)
    q3d = weighted_quantile(freqs, durations, 0.75)
    q1c = weighted_quantile(freqs, counts, 0.25)
    q2c = weighted_quantile(freqs, counts, 0.50)
    q3c = weighted_quantile(freqs, counts, 0.75)

    return {
        "q0_hz": round(min(freqs), 2),
        "q1_hz_dur": round(q1d, 2),
        "q2_hz_dur": round(q2d, 2),
        "q3_hz_dur": round(q3d, 2),
        "q4_hz": round(max(freqs), 2),
        "q1_hz_cnt": round(q1c, 2),
        "q2_hz_cnt": round(q2c, 2),
        "q3_hz_cnt": round(q3c, 2),
        "tessitura_width_dur": round(q3d - q1d, 2),
        "tessitura_width_cnt": round(q3c - q1c, 2),
    }


@feature(
    name="vocal_load", group="vocal", scope="part", source="songfeat",
    description=(
        "Phonatory load: total vibrations (cycle dose), time spent sounding, "
        "rest, and sustained-note burden."
    ),
    fields=LOAD_FIELDS,
)
def vocal_load(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(LOAD_FIELDS)

    context = PartContext(part, piece)
    dose = sum(
        midi_to_hz(n.midi) * (n.duration_seconds or 0.0) for n in part.notes
    )
    sounding = sum(n.duration_seconds or 0.0 for n in part.notes)
    total = piece.duration_seconds or sounding
    rest = max(total - sounding, 0.0)

    return {
        "cycle_dose": round(dose, 2),
        "time_dose_seconds": round(sounding, 2),
        "rest_seconds": round(rest, 2),
        "rest_ratio": round(rest / total, 4) if total else None,
        "sustained_note_count": len(context.sustained),
        "sustained_seconds": round(
            sum(n.duration_seconds or 0.0 for n in context.sustained), 2
        ),
    }
```

```python
    return tuple(names)

#: Ratio of one semitone, used to widen a zone for proximity.
_SEMITONE = 2.0 ** (1.0 / 12.0)


def in_zone(hz: float, zone: tuple[float, float]) -> bool:
    low, high = zone
    return low <= hz <= high


def near_zone(hz: float, zone: tuple[float, float]) -> bool:
    margin = _SEMITONE ** PASSAGGIO_PROXIMITY_SEMITONES
    low, high = zone
    return (low / margin) <= hz <= (high * margin)


@feature(
    name="passaggi", group="vocal", scope="part", source="songfeat",
    description=(
        "Dwell time, proximity, crossings and longest continuous span in each "
        "of the nine passaggio zones, for high, medium and low voice."
    ),
    fields=PASSAGGI_FIELDS,
    citation="Zones from src/tessitura.py:76-84; pedagogical source unconfirmed.",
)
def passaggi(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(PASSAGGI_FIELDS)

    notes = sorted(part.notes, key=lambda n: n.onset)
    sounding = sum(n.duration_seconds or 0.0 for n in notes)
    out: dict[str, Any] = {}

    for voice, registers in PASSAGGI.items():
        zones = list(registers.values())
        for register, zone in registers.items():
            seconds = sum(
                (n.duration_seconds or 0.0)
                for n in notes
                if in_zone(midi_to_hz(n.midi), zone)
            )
            out[f"pass_{voice}_{register}_seconds"] = round(seconds, 2)
            out[f"pass_{voice}_{register}_pct"] = (
                round(100.0 * seconds / sounding, 2) if sounding else 0.0
            )

        inside_flags = [
            any(in_zone(midi_to_hz(n.midi), z) for z in zones) for n in notes
        ]
        out[f"pass_{voice}_crossings"] = sum(
            1 for a, b in zip(inside_flags, inside_flags[1:]) if a != b
        )
        out[f"pass_{voice}_near_seconds"] = round(
            sum(
                (n.duration_seconds or 0.0)
                for n in notes
                if any(near_zone(midi_to_hz(n.midi), z) for z in zones)
            ),
            2,
        )

        longest = current = 0.0
        for note, inside in zip(notes, inside_flags):
            current = current + (note.duration_seconds or 0.0) if inside else 0.0
            longest = max(longest, current)
        out[f"pass_{voice}_longest_span_seconds"] = round(longest, 2)

    return out
```

```python
# songfeat/features/vocal_phrasing.py
"""Phrase structure, breath demand, and runs."""

from __future__ import annotations

from statistics import fmean
from typing import Any

from ..constants import BREATH_DEMAND_SECONDS
from ..context import PartContext
from ..model import Note, Part, Piece
from .base import feature

PHRASE_FIELDS = (
    "n_phrases", "phrase_longest_seconds", "phrase_mean_seconds",
    "phrase_longest_notes", "n_phrases_over_breath_threshold",
)

RUN_FIELDS = (
    "n_runs", "run_longest_notes", "run_note_share", "runs_per_minute",
    "run_mean_notes_per_second",
)


def _span_seconds(notes: list[Note]) -> float:
    """Onset of the first note to the end of the last."""
    if not notes:
        return 0.0
    start = notes[0].onset_seconds or 0.0
    last = notes[-1]
    return max((last.onset_seconds or 0.0) + (last.duration_seconds or 0.0) - start, 0.0)


@feature(
    name="phrasing", group="vocal", scope="part", source="songfeat",
    description=(
        "Phrase structure derived from rest gaps, and how many phrases exceed "
        "a sustained-breath threshold."
    ),
    fields=PHRASE_FIELDS,
)
def phrasing(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(PHRASE_FIELDS)

    phrases = PartContext(part, piece).phrases
    spans = [_span_seconds(p) for p in phrases]
    return {
        "n_phrases": len(phrases),
        "phrase_longest_seconds": round(max(spans), 2) if spans else 0.0,
        "phrase_mean_seconds": round(fmean(spans), 2) if spans else 0.0,
        "phrase_longest_notes": max((len(p) for p in phrases), default=0),
        "n_phrases_over_breath_threshold": sum(
            1 for s in spans if s >= BREATH_DEMAND_SECONDS
        ),
    }


@feature(
    name="runs", group="vocal", scope="part", source="songfeat",
    description=(
        "Fast stepwise or scalar passages: how many, how long, how much of "
        "the line they occupy, and how fast they move."
    ),
    fields=RUN_FIELDS,
)
def runs(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(RUN_FIELDS)

    context = PartContext(part, piece)
    found = context.runs
    in_runs = sum(len(r) for r in found)
    total_seconds = piece.duration_seconds or 0.0
    run_seconds = sum(_span_seconds(r) for r in found)

    return {
        "n_runs": len(found),
        "run_longest_notes": max((len(r) for r in found), default=0),
        "run_note_share": (
            round(in_runs / len(context.monophonic), 4) if context.monophonic else 0.0
        ),
        "runs_per_minute": (
            round(60.0 * len(found) / total_seconds, 3) if total_seconds else None
        ),
        "run_mean_notes_per_second": (
            round(in_runs / run_seconds, 3) if run_seconds else None
        ),
    }
```

```python
# songfeat/features/vocal_intervals.py
"""Leaps and chromaticism.

Chromaticism is measured against the prevailing key signature. MIDI has no
spelling, so this is an inference; MusicXML input yields a stronger reading
of the same columns. That difference is recorded in feature metadata.
"""

from __future__ import annotations

import math
from collections import Counter
from typing import Any

from ..constants import LEAP_MIN_SEMITONES, PASSAGGI
from ..context import PartContext
from ..model import Part, Piece
from .base import feature
from .vocal_pitch import midi_to_hz

LEAP_FIELDS = (
    "leap_max_semitones", "leap_share_gt2", "leap_share_gt4", "leap_share_gt7",
    "n_leaps_over_octave", "n_consecutive_leaps", "n_unprepared_leaps",
    "n_leaps_into_extremes", "leap_ascending_share",
    "n_leaps_crossing_passaggio", "interval_mean_abs",
)

CHROMA_FIELDS = (
    "nondiatonic_share", "chromatic_run_longest", "pitch_class_entropy",
    "n_distinct_pitch_classes",
)

#: Semitone offsets of the major scale from the tonic.
MAJOR_STEPS = (0, 2, 4, 5, 7, 9, 11)

#: Tonic pitch class implied by a key signature, indexed by sharp count.
_SHARP_TONICS = (0, 7, 2, 9, 4, 11, 6, 1)
_FLAT_TONICS = (0, 5, 10, 3, 8, 1, 6, 11)


def _tonic_pitch_class(sharps: int) -> int:
    table = _SHARP_TONICS if sharps >= 0 else _FLAT_TONICS
    return table[min(abs(sharps), 7)]


@feature(
    name="leaps", group="vocal", scope="part", source="songfeat",
    description=(
        "Melodic leaps quantified several ways: size, frequency, direction, "
        "preparation, and whether they cross a passaggio zone."
    ),
    fields=LEAP_FIELDS,
)
def leaps(part: Part, piece: Piece) -> dict[str, Any]:
    context = PartContext(part, piece)
    intervals = context.intervals
    if not intervals:
        return dict.fromkeys(LEAP_FIELDS)

    line = context.monophonic
    sizes = [abs(i) for i in intervals]
    leap_indices = [i for i, size in enumerate(sizes) if size >= LEAP_MIN_SEMITONES]
    n = len(intervals)

    midis = [note.midi for note in line]
    low, high = min(midis), max(midis)
    span = high - low
    extreme_low = low + span * 0.1
    extreme_high = high - span * 0.1

    consecutive = sum(
        1 for a, b in zip(leap_indices, leap_indices[1:]) if b == a + 1
    )

    unprepared = 0
    for i in leap_indices:
        if i + 1 >= n:
            unprepared += 1
            continue
        follows = intervals[i + 1]
        same_direction = (follows > 0) == (intervals[i] > 0)
        if abs(follows) >= LEAP_MIN_SEMITONES or same_direction:
            unprepared += 1

    zones = [z for registers in PASSAGGI.values() for z in registers.values()]
    crossing = 0
    for i in leap_indices:
        start_hz, end_hz = midi_to_hz(line[i].midi), midi_to_hz(line[i + 1].midi)
        lo, hi = sorted((start_hz, end_hz))
        if any(lo < zone[1] and hi > zone[0] for zone in zones):
            crossing += 1

    ascending = sum(1 for i in leap_indices if intervals[i] > 0)

    return {
        "leap_max_semitones": max(sizes),
        "leap_share_gt2": round(sum(1 for s in sizes if s > 2) / n, 4),
        "leap_share_gt4": round(sum(1 for s in sizes if s > 4) / n, 4),
        "leap_share_gt7": round(sum(1 for s in sizes if s > 7) / n, 4),
        "n_leaps_over_octave": sum(1 for s in sizes if s > 12),
        "n_consecutive_leaps": consecutive,
        "n_unprepared_leaps": unprepared,
        "n_leaps_into_extremes": sum(
            1 for i in leap_indices
            if line[i + 1].midi <= extreme_low or line[i + 1].midi >= extreme_high
        ),
        "leap_ascending_share": (
            round(ascending / len(leap_indices), 4) if leap_indices else 0.0
        ),
        "n_leaps_crossing_passaggio": crossing,
        "interval_mean_abs": round(sum(sizes) / n, 3),
    }


@feature(
    name="chromaticism", group="vocal", scope="part", source="songfeat",
    description=(
        "Departure from the prevailing diatonic collection. Inferred from the "
        "key signature; stronger for MusicXML input, which carries spelling."
    ),
    fields=CHROMA_FIELDS,
    best_with=("musicxml", "humdrum", "mei"),
)
def chromaticism(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(CHROMA_FIELDS)

    context = PartContext(part, piece)
    line = context.monophonic

    outside = 0
    for note in line:
        mark = context.prevailing_key(note.onset)
        tonic = _tonic_pitch_class(mark.sharps if mark else 0)
        if (note.midi - tonic) % 12 not in MAJOR_STEPS:
            outside += 1

    longest = current = 0
    for a, b in zip(line, line[1:]):
        current = current + 1 if abs(b.midi - a.midi) == 1 else 0
        longest = max(longest, current + 1 if current else 0)

    counts = Counter(note.midi % 12 for note in line)
    total = sum(counts.values())
    entropy = -sum(
        (c / total) * math.log2(c / total) for c in counts.values() if c
    )

    return {
        "nondiatonic_share": round(outside / len(line), 4),
        "chromatic_run_longest": longest,
        "pitch_class_entropy": round(entropy, 4),
        "n_distinct_pitch_classes": len(counts),
    }
```

```python
"""Text setting: syllable count and melismatic writing.

A melisma is two or more consecutive notes sung on one syllable. Lyric
events mark the note that begins a syllable, so a note carrying no lyric
continues the previous one.
"""

from __future__ import annotations

from typing import Any

from ..context import PartContext
from ..model import Part, Piece
from .base import feature

TEXT_FIELDS = (
    "n_syllables", "notes_per_syllable", "melisma_longest_notes",
    "melisma_share", "n_melismas", "syllables_per_second",
)


@feature(
    name="text_setting", group="vocal", scope="part", source="songfeat",
    description=(
        "Syllable count and melismatic writing: how many notes each syllable "
        "carries, and how much of the line is melismatic."
    ),
    fields=TEXT_FIELDS,
)
def text_setting(part: Part, piece: Piece) -> dict[str, Any]:
    if part.is_empty:
        return dict.fromkeys(TEXT_FIELDS)

    line = PartContext(part, piece).monophonic
    syllables = sum(1 for note in line if note.lyric)

    if syllables == 0:
        return {
            "n_syllables": 0,
            "notes_per_syllable": None,
            "melisma_longest_notes": None,
            "melisma_share": None,
            "n_melismas": None,
            "syllables_per_second": None,
        }

    groups: list[int] = []
    for note in line:
        if note.lyric or not groups:
            groups.append(1)
        else:
            groups[-1] += 1

    melismas = [size for size in groups if size >= 2]
    total_seconds = piece.duration_seconds or 0.0

    return {
        "n_syllables": syllables,
        "notes_per_syllable": round(len(line) / syllables, 3),
        "melisma_longest_notes": max(groups),
        "melisma_share": round(sum(melismas) / len(line), 4),
        "n_melismas": len(melismas),
        "syllables_per_second": (
            round(syllables / total_seconds, 3) if total_seconds else None
        ),
    }
```

```python
# songfeat/sinks/sheets.py
"""Append feature rows to a Google Sheet.

The Google client is an optional dependency: importing songfeat must not
require it, so the import happens inside the constructor. Rows are
appended in batches because the Sheets write quota is per minute and per
user, and a 150-file corpus with several parts each is enough to hit it.
"""

from __future__ import annotations

import os
from typing import Any

from ..record import FeatureRecord
from .base import BaseSink


class SheetsSink(BaseSink):
    def __init__(
        self,
        spreadsheet_id: str,
        worksheet: str = "songfeat",
        credentials_env: str = "GOOGLE_APPLICATION_CREDENTIALS",
        batch_size: int = 200,
        client: Any = None,
    ) -> None:
        if client is None:
            try:
                import gspread
            except ImportError as exc:  # pragma: no cover - exercised by hand
                raise ImportError(
                    "SheetsSink needs the optional Google client. "
                    "Install it with: pip install gspread"
                ) from exc
            path = os.environ.get(credentials_env)
            if not path:
                raise RuntimeError(
                    f"{credentials_env} is not set. It must point at a service "
                    "account JSON file. Never commit that file."
                )
            client = gspread.service_account(filename=path)

        self._client = client
        self.spreadsheet_id = spreadsheet_id
        self.worksheet_title = worksheet
        self.batch_size = batch_size
        self._worksheet = None
        self._pending: list[list[Any]] = []

    def open(self, schema: list[str]) -> None:
        super().open(schema)
        self._worksheet = self._client.open_by_key(
            self.spreadsheet_id
        ).worksheet(self.worksheet_title)
        if not self._worksheet.get_all_values():
            self._worksheet.append_rows([self.schema], value_input_option="RAW")

    def write(self, record: FeatureRecord) -> None:
        row = record.flat()
        self._pending.append([row.get(column, "") for column in self.schema])
        if len(self._pending) >= self.batch_size:
            self._flush()

    def _flush(self) -> None:
        if self._pending:
            self._worksheet.append_rows(self._pending, value_input_option="RAW")
            self._pending = []

    def close(self) -> None:
        self._flush()
```

```python
# songfeat/profile.py
"""Report which feature columns actually carry information.

Borrowed feature batteries include columns that are meaningless for a
single monophonic vocal line. This finds them before a modelling cycle
does.
"""

from __future__ import annotations

import statistics
from dataclasses import dataclass
from itertools import combinations
from typing import Any, Iterable

from .record import FeatureRecord


@dataclass
class FeatureProfile:
    name: str
    null_rate: float
    n_distinct: int
    is_constant: bool
    variance: float | None
    dtype: str


def _column_names(records: list[FeatureRecord]) -> list[str]:
    seen: list[str] = []
    for record in records:
        for name in record.features:
            if name not in seen:
                seen.append(name)
    return seen


def profile_records(records: Iterable[FeatureRecord]) -> list[FeatureProfile]:
    records = list(records)
    if not records:
        return []

    profiles: list[FeatureProfile] = []
    for name in _column_names(records):
        values = [r.features.get(name) for r in records]
        present = [v for v in values if v is not None]
        numeric = [v for v in present if isinstance(v, (int, float))
                   and not isinstance(v, bool)]

        variance = (
            statistics.pvariance(numeric)
            if len(numeric) > 1 and len(numeric) == len(present)
            else None
        )
        distinct = len(set(present))
        profiles.append(
            FeatureProfile(
                name=name,
                null_rate=round(1.0 - len(present) / len(values), 4),
                n_distinct=distinct,
                is_constant=distinct <= 1,
                variance=round(variance, 6) if variance is not None else None,
                dtype=type(present[0]).__name__ if present else "null",
            )
        )
    return profiles


def correlated_pairs(
    records: Iterable[FeatureRecord], threshold: float = 0.95
) -> list[tuple[str, str, float]]:
    """Numeric column pairs whose absolute correlation reaches the threshold."""
    records = list(records)
    if not records:
        return []

    columns: dict[str, list[float]] = {}
    for name in _column_names(records):
        values = [r.features.get(name) for r in records]
        if all(
            isinstance(v, (int, float)) and not isinstance(v, bool) for v in values
        ):
            columns[name] = [float(v) for v in values]

    found: list[tuple[str, str, float]] = []
    for left, right in combinations(columns, 2):
        a, b = columns[left], columns[right]
        if len(a) < 2 or len(set(a)) <= 1 or len(set(b)) <= 1:
            continue
        r = statistics.correlation(a, b)
        if abs(r) >= threshold:
            found.append((left, right, round(r, 4)))
    return found
```

```python
This reports agreement; it does not assert it. The reference spreadsheet
and the reference implementation disagree about the tessitura quartiles,
so a pass/fail gate here would encode one of two unreconciled answers.

    "t", "tr", "Fptp", "Q0p", "Q1p", "Q2p", "Q3p", "Q4p",
    "Hp tp", "Hp %p", "Mp tp", "Mp %p", "Lp tp", "Lp %p",
)

#: Absolute tolerances per quantity.

DEFAULT_TOLERANCE = 0.5


@dataclass
class Comparison:
    aria: str
    quantity: str
    expected: float
    actual: float | None
    delta: float | None
    within_tolerance: bool


def load_ground_truth(xlsx_path: str) -> dict[str, dict[str, float]]:
    """Read the labelled summary cells from every per-aria sheet."""
    book = pd.ExcelFile(xlsx_path)
    truth: dict[str, dict[str, float]] = {}
    for sheet in book.sheet_names:
        if sheet == "Tab Master":
            continue
        frame = book.parse(sheet, header=None)
        values: dict[str, float] = {}
        for row in range(min(40, frame.shape[0])):
            for column in range(min(12, frame.shape[1] - 1)):
                cell = frame.iat[row, column]
                if isinstance(cell, str) and cell.strip() in GROUND_TRUTH_LABELS:
                    neighbour = frame.iat[row, column + 1]
                    if isinstance(neighbour, (int, float)):
                        values[cell.strip()] = float(neighbour)
        truth[sheet] = values
    return truth


def _roman_to_path(corpus_dir: str, roman: str) -> str | None:
    for name in os.listdir(corpus_dir):
        if name.endswith(f"-{roman}.mid"):
            return os.path.join(corpus_dir, name)
    return None


def compare(
    corpus_dir: str, xlsx_path: str, arias: list[str] | None = None
) -> list[Comparison]:
    truth = load_ground_truth(xlsx_path)
    wanted = arias or list(truth)
    results: list[Comparison] = []

    for roman in wanted:
        path = _roman_to_path(corpus_dir, roman)
        if path is None or not truth.get(roman):
            continue
        piece = load(path, drop_trailing_marker=True)
        out = base.extract_part(piece.parts[0], piece, groups_filter=["vocal"])

        pairs = [
            ("t", out.get("time_dose_seconds", 0) + out.get("rest_seconds", 0)),
            ("tr", out.get("rest_seconds")),
            ("Fptp", out.get("cycle_dose")),
            ("Q0p", out.get("q0_hz")),
            ("Q4p", out.get("q4_hz")),
            ("Q1p (duration-weighted)", out.get("q1_hz_dur")),
            ("Q2p (duration-weighted)", out.get("q2_hz_dur")),
            ("Q3p (duration-weighted)", out.get("q3_hz_dur")),
            ("Q1p (count-weighted)", out.get("q1_hz_cnt")),
            ("Q2p (count-weighted)", out.get("q2_hz_cnt")),
            ("Q3p (count-weighted)", out.get("q3_hz_cnt")),
        ]

        for quantity, actual in pairs:
            label = quantity.split(" (")[0]
            if label not in truth[roman]:
                continue
            expected = truth[roman][label]
            delta = None if actual is None else actual - expected
            tolerance = TOLERANCES.get(label, DEFAULT_TOLERANCE)
            results.append(
                Comparison(
                    aria=roman,
                    quantity=quantity,
                    expected=expected,
                    actual=actual,
                    delta=delta,
                    within_tolerance=delta is not None and abs(delta) <= tolerance,
                )
            )
    return results
```

```python
def compare_to_reference(corpus_dir: str, limit: int | None = None) -> list[Comparison]:
    """Diff our values against what upstream main.py prints.

    The reference CLI writes a PDF and prints a report; we parse the report.
    Any divergence is a defect in one implementation or the other.
    """
    import re
    import subprocess

    pattern = re.compile(
        r"Compositional Range: ([\d.]+)-([\d.]+) Hz.*?"
        r"Tessitura Range:\s+([\d.]+)-([\d.]+) Hz.*?"
        r"Median Frequency: ([\d.]+) Hz.*?"
        r"Cycle Dose: ([\d.]+).*?"
        r"Total Time: ([\d.]+)s",
        re.S,
    )
    results: list[Comparison] = []
    paths = sorted(
        os.path.join(corpus_dir, n)
        for n in os.listdir(corpus_dir)
        if n.endswith(".mid")
    )[:limit]

    for path in paths:
        completed = subprocess.run(
            ["venv/bin/python", "main.py", "--filepath", path],
            capture_output=True, text=True,
        )
        match = pattern.search(completed.stdout.replace("\u2013", "-"))
        if not match:
            continue
        low, high, t_low, t_high, median, dose, total = (
            float(g) for g in match.groups()
        )
        piece = load(path, drop_trailing_marker=True)
        out = base.extract_part(piece.parts[0], piece, groups_filter=["vocal"])
        aria = os.path.basename(path)
        for quantity, expected, actual in (
            ("ref Q0p", low, out["q0_hz"]),
            ("ref Q4p", high, out["q4_hz"]),
            ("ref median (dur)", median, out["q2_hz_dur"]),
            ("ref median (cnt)", median, out["q2_hz_cnt"]),
            ("ref cycle dose", dose, out["cycle_dose"]),
        ):
            delta = None if actual is None else actual - expected
            results.append(
                Comparison(
                    aria=aria, quantity=quantity, expected=expected,
                    actual=actual, delta=delta,
                    within_tolerance=delta is not None and abs(delta) <= 1.0,
                )
            )
    return results
```

```python
# tests/test_songfeat/test_properties.py
"""Invariants that hold whatever the feature definitions turn out to be.

Every test here loops over the corpus sample, so an empty or partially
loaded sample would make the whole file pass while asserting nothing.
`test_the_sample_loaded` exists to make that failure loud, and the
filtered tests count what they checked for the same reason.
"""

import os

import pytest

from songfeat.pipeline import analyze_file

CORPUS = os.path.join("data", "test_data_arias")
SAMPLE = [os.path.join(CORPUS, n) for n in sorted(os.listdir(CORPUS))[:12]]

#: Borrowed music21 extractors that fail on a reconstructed single part.
#: Imported from the adapter's own test module so the two cannot drift.
from tests.test_songfeat.test_pipeline import EXPECTED_BORROWED_FAILURES


@pytest.fixture(scope="module")
def records():
    out = []
    for path in SAMPLE:
        out.extend(analyze_file(path, drop_trailing_marker=True))
    return out


def test_the_sample_loaded(records):
    """Guards every other test in this file.

    All of them iterate `records`; an empty list would make each one pass
    vacuously. The corpus files are single-part, so one record per file.
    """
    assert len(SAMPLE) == 12, SAMPLE
    assert len(records) == len(SAMPLE), [r.source_path for r in records]


def _checked(values):
    """Assert a filtered test actually found something, then return it."""
    assert values, "filter matched no columns; the test would assert nothing"
    return values


def test_quartiles_are_ordered(records):
    for record in records:
        f = record.features
        ordered = [f["q0_hz"], f["q1_hz_dur"], f["q2_hz_dur"], f["q3_hz_dur"], f["q4_hz"]]
        # Duration-weighted quartiles are None on a part with no sounding
        # time; the extremes stay real. Skip rather than crash on sorted().
        if any(v is None for v in ordered):
            continue
        assert ordered == sorted(ordered), record.source_path


def test_count_weighted_quartiles_are_also_ordered(records):
    for record in records:
        f = record.features
        trio = [f["q1_hz_cnt"], f["q2_hz_cnt"], f["q3_hz_cnt"]]
        if any(v is None for v in trio):
            continue
        assert trio[0] <= trio[1] <= trio[2], record.source_path


def test_durations_are_non_negative(records):
    seen = 0
    for record in records:
        for field in ("cycle_dose", "time_dose_seconds", "rest_seconds"):
            value = record.features[field]
            if value is None:        # rest_seconds is None when total time is unknown
                continue
            seen += 1
            assert value >= 0, (record.source_path, field)
    assert seen, "no duration values were checked"


def test_rest_ratio_is_a_proportion(records):
    seen = 0
    for record in records:
        value = record.features["rest_ratio"]
        if value is None:
            continue
        seen += 1
        assert 0.0 <= value <= 1.0, record.source_path
    assert seen, "no rest_ratio values were checked"


def test_passaggio_percentages_never_exceed_one_hundred(records):
    checked = _checked([
        (r.source_path, name, value)
        for r in records
        for name, value in r.features.items()
        if name.endswith("_pct") and value is not None
    ])
    for path, name, value in checked:
        assert 0.0 <= value <= 100.0, (path, name)


def test_phrase_time_does_not_exceed_total_time(records):
    seen = 0
    for record in records:
        longest = record.features["phrase_longest_seconds"]
        sounding = record.features["time_dose_seconds"]
        rest = record.features["rest_seconds"]
        if None in (longest, sounding, rest):
            continue
        seen += 1
        assert longest <= sounding + rest + 0.01, record.source_path
    assert seen, "no phrase durations were checked"


def test_shares_are_proportions(records):
    checked = _checked([
        (r.source_path, name, value)
        for r in records
        for name, value in r.features.items()
        if name.endswith("_share") and value is not None
    ])
    for path, name, value in checked:
        assert 0.0 <= value <= 1.0, (path, name)


def test_only_the_known_borrowed_features_error(records):
    """The error set is pinned, not asserted empty.

    Roughly a dozen jSymbolic and native extractors are unimplemented in
    music21 or meaningless on a reconstructed single part. Asserting zero
    errors would fail; asserting equality catches a NEW failure appearing
    or a known one silently disappearing.
    """
    failed = {name for r in records for name in r.errors}
    assert failed == EXPECTED_BORROWED_FAILURES, {
        "unexpected": sorted(failed - EXPECTED_BORROWED_FAILURES),
        "no longer failing": sorted(EXPECTED_BORROWED_FAILURES - failed),
    }


def test_every_record_has_the_full_schema(records):
    from songfeat.features import base
    expected = set(base.schema()) - set(type(records[0]).IDENTITY)
    assert expected, "schema minus identity columns was empty"
    for record in records:
        assert expected <= set(record.features), record.source_path
```
